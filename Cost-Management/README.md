# AWS Cost Management

## Overview
In a production environment, uncontrolled cloud spending can lead to unnecessary financial impact. This lab demonstrates the implementation of AWS Budgets to improve cost visibility and maintain spending awareness across cloud resources.

## Objectives
- Monitor monthly AWS spending
- Configure automated billing alerts
- Improve cloud cost awareness and governance

## Technical Implementation
- Budget Type: Monthly Cost Budget
- Budget Limit: $5 USD
- Alert Thresholds:
  - 85% actual usage
  - 100% actual usage
  - Forecasted over-budget alert
- Notification Method: Email alerts

## Services Used
- AWS Budgets
- AWS Billing and Cost Management
